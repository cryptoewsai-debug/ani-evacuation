## Session Contract

Every session must end with a 4-part summary written to `Ani/sessions/`:
1. Summary — What was done, tools used, key findings
2. Hanging Actions — What's pending or needs follow-up
3. Notices — Any blockers, auth needs, or important notes
4. Next Session Start Point — Clear entry point for continuation

## Daily Log

At ~22:00 EEST, a daily summary is sent to `crypto.ews.ai@icloud.com` with the session's key findings and protocol state updates.
